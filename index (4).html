3. The answer: watch the ambulance go! 🚑

Shortest route: Fire Station → Sector 21 → Sector 14 → Market → Bus Stand → Hospital
Total distance: 13 km

Dijkstra always picks the nearest unfinished place, so a place is never made shorter later. This works because road lengths are never negative.

6. 💻 The code: how the algorithm works

This is the heart of Dijkstra’s algorithm in C++. Read the numbers in the comments, then the explanation below.

// 1. Start: every place is "far away", except the start
for (int i = 0; i < V; i++) dist[i] = INF;
dist[start] = 0;

for (int count = 0; count < V; count++) {
    // 2. Pick the nearest place that is not finished yet
    int u = -1;
    for (int i = 0; i < V; i++)
        if (!done[i] && (u == -1 || dist[i] < dist[u])) u = i;

    done[u] = true;                        // 3. Its distance is now final

    // 4. Try to improve its neighbours
    for (int v = 0; v < V; v++)
        if (road[u][v] > 0 && dist[u] + road[u][v] < dist[v]) {
            dist[v] = dist[u] + road[u][v];   // shorter way found!
            parent[v] = u;                    // remember where we came from
        }
}
  1. Start: the Fire Station has distance 0. Every other place is ∞ because we do not know a way there yet.
  2. Pick the nearest unfinished place (the inner loop with dist[i] < dist[u]). This is the greedy step.
  3. Mark it finished. Roads are never negative, so nothing can make this distance smaller later.
  4. Relax the neighbours: if going through u is shorter than the old distance, save the new distance and remember parent[v] = u.
  5. Repeat until every place is finished. To get the route, start at the Hospital and follow parent back to the Fire Station.
Think of it like this: you are in a new city and always visit the closest shop you have not visited yet. Each time you arrive somewhere, you check if it gives a shortcut to the shops around it. Click through the step viewer above to see exactly this happen.

8. How fast is it?

Dijkstra

Time O(V²) (array version)
or O((V+E) log V) with a priority queue.
Needs non-negative road lengths.

Bellman–Ford

Time O(V × E)
Slower, but allows negative lengths.

Limitation

This model uses only distance. Real maps also have traffic and one-way roads.
